FrreeBSD 15.1 NVIDIA-DRM-Latest-Kmod Compile and Setup Guide

Clone FreeBSD Ports Tree (Non-interactive/Batch):
pkg install -y git
git clone --depth 1 https://git.FreeBSD.org/ports.git /usr/ports

. Prepare Kernel Sources:
git clone -b releng/15.1 https://git.freebsd.org/src.git /usr/src

. Compile and Install DRM and NVIDIA Modules (Using BATCH=yes to skip config dialogs):
cd /usr/ports/graphics/drm-latest-kmod
make BATCH=yes install clean

cd /usr/ports/graphics/nvidia-drm-latest-kmod
make BATCH=yes install clean

4. Configure Kernel Module Loading (/boot/loader.conf):
nvidia_driver_load="YES"
nvidia-modeset_load="YES"
nvidia-drm_load="YES"

't hw.nvidia.registry.EnableGpuFirmware=1

Update RC Configuration (/etc/rc.conf):
kld_list="... nvidia-drm"

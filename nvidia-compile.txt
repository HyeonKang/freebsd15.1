1. FreeBSD 15-STABLE 버전을 사용 중인 경우
git clone --depth 1 -b stable/15 https://git.freebsd.org/src.git /usr/src
2. FreeBSD 15.1-RELEASE 정식 버전을 사용 중인 경우
안정성을 위해 패치(보안 업데이트) 단위의 소스 코드만 추적하고 싶다면 releng 브랜치를 지정해야 합니다. [1, 2]
git clone --depth 1 -b releng/15.1 https://git.freebsd.org/src.git /usr/src
3. FreeBSD 15-CURRENT (최첨단 개발 버전)을 사용 중인 경우
가장 최신 개발 트리를 사용 중인 경우 main 브랜치를 사용합니다. [1]

git clone --depth 1 -b main https://git.freebsd.org/src.git /usr/src

FreeBSD 포트 트리(ports) 우회 다운로드:
git clone --depth 1 -b main https://git.freebsd.org/ports.git /usr/ports


4. Ports를 통한 nvidia-drm-latest-kmod 컴파일 및 설치
cd /usr/ports/graphics/nvidia-drm-latest-kmod
make install clean BATCH=yes

설치가 완료되면 /etc/rc.conf 수정 
sysrc kld_list+="nvidia nvidia-modeset nvidia-drm"


/boot/loader.conf 수정 (필요한 경우 EFI 프레임버퍼 비활성화)
hw.syscons.disable=1

*******트러블슈팅
cd /usr/ports/graphics/nvidia-drm-latest-kmod
make deinstall
make clean
make install clean


운영체제의 커널 종류를 모르신다면, uname -v를 입력
